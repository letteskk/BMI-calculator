# Калькулятор ИМТ

## Что это? 
Калькулятор ИМТ - программа для расчёта индекса массы тела (отношение массы тела к квадрату роста). 

## Как открыть? 
Чтобы открыть этот сайт, нужно перейти по ссылке <https://letteskk.github.io/BMI-calculator/>. Можно открыть с компьютера, планшета и телефона. 

## Как использовать?
Введите свой рост и вес в соответствующие строки, выберите пол и нажмите кнопку "рассчитать". После этого вы увидите результат и его оценку (дефицит веса, нормальный вес, избыточный вес). С помощью изображения флага в левом верхнем углу страницы можно сменить язык с русского на английский и наоборот.

# BMI Calculator

## What is it?
BMI Calculator is a program for calculating body mass index (ratio of body mass to height squared).

## How do I open it?
To open this website, you shoud follow this link: <https://letteskk.github.io/BMI-calculator/>. The website can be opened on a computer, tablet and mobile phone.

## How do I use it?
Input your height and weight in the corresponding fields, choose your sex and click the "calculate" button. After that you'll see the result and its evaluation (underweight, normal weight, overweight). You can change language from Russian to English and vice versa using the flag image in the top-left corner of the page.
